# Smart Buy Advisor

🛒 **Shopping Consultant** — a Next.js (App Router) pet project for helping users choose laptops, powered by a chat-bot (Mistral AI).

## Features

- User authentication and registration (JWT)
- Chat-bot for laptop selection (answers only about laptops)
- Chat history and saved sessions
- Voice input, markdown tables, and link parsing
- Toast notifications (Sonner)
- Clean, modern UI (React + Next.js)

## Stack

- Next.js (App Router)
- React
- MySQL (or your DB)
- Sonner (toast notifications)
- React Markdown
- Mistral AI
